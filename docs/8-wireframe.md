### 인터랙션 설명

- **로그인 버튼 클릭**: 아이디/비밀번호 입력값을 API로 전송. 성공 시 JWT 저장 후 할일 목록 화면(`/todos`)으로 이동
- **오류 상태**: 잘못된 자격증명 입력 시 "아이디 또는 비밀번호가 올바르지 않습니다." 표시. 비활성화 계정은 "비활성화된 계정입니다. 관리자에게 문의하세요." 표시
- **로딩 상태**: 로그인 버튼 클릭 후 API 응답 대기 중 버튼 내부에 스피너(⟳) 표시 및 버튼 비활성화
- **회원가입 링크**: 클릭 시 회원가입 화면(`/register`)으로 이동
- **인증 보호**: 이미 로그인된 상태에서 해당 화면 접근 시 할일 목록으로 리다이렉트

### 인터랙션 설명

- **회원가입 버튼 클릭**: 입력값 유효성 검증(아이디 형식, 비밀번호 길이) 후 API 요청. 성공 시 로그인 화면으로 이동

- **클라이언트 유효성 검증**: 아이디 미입력/형식 오류, 비밀번호 4자 미만 시 버튼 클릭 전 인라인 안내 표시
- **로딩 상태**: 회원가입 버튼 클릭 후 API 응답 대기 중 버튼 내부에 스피너(⟳) 표시
- **로그인 링크**: 클릭 시 로그인 화면(`/login`)으로 이동

### 인터랙션 설명

- **카테고리 필터**: 드롭다운에서 특정 카테고리 선택 시 해당 카테고리 할일만 표시. "전체" 선택 시 카테고리 미지정 할일 포함 전체 표시 (FR-17)
- **상태 필터**: PENDING / COMPLETED / OVERDUE / 전체 중 선택하여 목록 필터링 (FR-06)
- **OVERDUE 시각 구분**: 빨간 테두리 + 배경 연한 빨강으로 카드 강조. [! OVERDUE] Badge 빨간색 표시 (FR-12)
- **완료 처리 버튼**: PENDING, OVERDUE 상태 카드에 표시. 클릭 시 확인 없이 즉시 COMPLETED 전환, completedAt 기록 (FR-10)
- **완료 취소 버튼**: COMPLETED 상태 카드에 표시. 클릭 시 확인 없이 즉시 PENDING 전환, completedAt 초기화 (FR-11)
- **수정 버튼(✎)**: 클릭 시 할일 등록/수정 화면으로 이동
- **삭제 버튼(🗑)**: 클릭 시 확인 Dialog(WF-07) 표시 후 삭제 처리
- **로딩 상태**: 목록 최초 로드 또는 필터 변경 시 목록 영역에 스피너(⟳) 표시
- **빈 상태**: 해당 필터 조건에 할일이 없을 때 WF-08 빈 상태 컴포넌트 표시

### 인터랙션 설명

- **접근 권한**: ADMIN 역할 보유자만 접근 가능. 일반 USER가 URL 직접 접근 시 403 처리 후 할일 목록으로 리다이렉트
- **목록 표시 항목**: 전체 사용자의 username, role, isActive(활성/비활성), createdAt 표시 (FR-18)
- **활성 상태 표시**: isActive true = "● 활성" (초록 점), isActive false = "✕ 비활성" (빨강 표시)
- **비활성화 버튼**: 활성 USER 계정에 표시. 클릭 시 확인 Dialog(WF-07) 표시 후 비활성화 처리 (FR-19)
- **활성화 버튼**: 비활성 USER 계정에 표시. 클릭 시 확인 Dialog(WF-07) 표시 후 활성화 처리 (FR-19)
- **admin 계정 비활성화 버튼**: disabled 상태로 렌더링하여 클릭 불가. 마우스 오버 시 "기본 관리자 계정은 비활성화할 수 없습니다." 툴팁 표시 (SC-AD-03, FR-19)
- **로딩 상태**: 목록 최초 로드 시 테이블 영역에 스피너(⟳) 표시

### 인터랙션 설명

- **트리거**: 삭제(🗑) 버튼 또는 비활성화/활성화 버튼 클릭 시 모달 표시

- **오버레이(░) 클릭**: Dialog 닫힘 (취소와 동일 동작)
- **확인 버튼 클릭**: API 요청 전송. 버튼 내 스피너(⟳) 표시 및 버튼 비활성화. 응답 수신 후 Dialog 닫힘 및 목록 갱신
- **확인 버튼 색상**: 삭제 액션은 빨간 배경, 활성화 관련 액션은 기본 파란 배경으로 위험도 구분
- **ESC 키**: Dialog 닫힘 (키보드 접근성)
- **포커스 트랩**: Dialog 열린 상태에서 Tab 키 포커스가 Dialog 내부에만 머뭄 (접근성)
